# User Stories

## US-01
As an end user, I want to create an Incident so that my issue can be reported.

## US-02
As a service desk agent, I want tickets to be automatically classified so that I spend less time on manual triage.

## US-03
As a support team member, I want incidents to reach the correct assignment group so that the responsible team can act on them.

## US-04
As an administrator, I want to maintain keyword rules so that classification can evolve with business requirements.

## Acceptance Criteria

- New Incident starts the flow.
- Matching keywords classify the Incident.
- Correct assignment group is populated.
- Unmatched Incident goes to default queue.
- Flow execution completes successfully.
