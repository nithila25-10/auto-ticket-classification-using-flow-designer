# 4. Project Planning

## Suggested 7-Day Plan

| Day | Task |
|---|---|
| Day 1 | Understand problem and ServiceNow Incident table |
| Day 2 | Gather requirements and classification rules |
| Day 3 | Design flow and assignment mapping |
| Day 4 | Build Flow Designer flow |
| Day 5 | Test positive and negative cases |
| Day 6 | Prepare documentation and screenshots |
| Day 7 | Final demonstration and presentation |

## Roles

### Student 1 – Administrator
Flow creation and configuration.

### Student 2 – Tester
Test cases and defect tracking.

### Student 3 – Documentation
Screenshots, report and presentation.

If working alone, perform the roles sequentially.

## Deliverables

- Flow Designer flow
- Classification rule document
- Test report
- Project report
- Demonstration script
- README
